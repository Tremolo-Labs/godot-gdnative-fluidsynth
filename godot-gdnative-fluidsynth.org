** Key API Changes (GDNative → GDExtension)

*** Class Registration
- Old: ~godot_nativescript_init()~ with manual bindings
- New: ~GDREGISTER_CLASS()~ in ~register_types.cpp~

*** Header Includes
- Old: ~#include <Godot.hpp>~, ~#include <Reference.hpp>~
- New: ~#include <godot_cpp/...>~ namespaced headers

*** Class Inheritance
- Old: ~class GDMidiPlayer : public AudioStreamPlayer~
- New: Uses ~GDCLASS()~ macro, ~ClassDB::bind_method()~

*** Entry Point
- Old: ~gdlibrary.cpp~ with ~godot_gdnative_init~
- New: ~register_types.cpp~ with GDExtension initialization
